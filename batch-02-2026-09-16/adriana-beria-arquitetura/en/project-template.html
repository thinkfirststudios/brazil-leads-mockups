How to publish a new project (internal mockup note)

  1. Duplicate this page and replace the name, project data and text.
  2. Confirm authorship (and co-authorship) and the client's written permission.
  3. Use only photos with a confirmed licence and fill in the photographer credit.
  4. Never publish an address, client name or identifying detail without permission.
  5. Add the card to the project grid on the home page.
