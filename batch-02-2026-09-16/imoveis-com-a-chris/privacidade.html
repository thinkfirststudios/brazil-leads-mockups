Este site não armazena os dados que você digita. O formulário “Fale com a Cris” apenas monta uma mensagem e abre o WhatsApp no seu aparelho. Nada é enviado a um servidor deste site: os dados só chegam à Cris se você enviar a mensagem no WhatsApp.
