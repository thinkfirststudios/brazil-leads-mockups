Antes de aplicar

Para quem é — e para quem não é

Para quem é

  • Já atuam, mas vivem no improviso
  • Trabalham muito e faturam pouco
  • Cobram sem segurança
  • Dependem de indicação
  • Sentem que o negócio não está sob controle

Para quem não é

  • Para quem não quer aplicar
  • Para quem busca só dica solta
  • Para quem não quer assumir responsabilidade pelo próprio negócio
