2. Dados coletados pelo site

Dados de saúde: informações odontológicas são dados pessoais sensíveis (LGPD, art. 5º, II). Os formulários deste site não coletam sintomas, condições, histórico odontológico ou motivo da consulta.

Menores de idade: este site não coleta dados de crianças e adolescentes. Agendamentos de menores são feitos pelo responsável legal, diretamente com a clínica (LGPD, art. 14).
